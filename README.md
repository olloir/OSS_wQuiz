# 영어 단어 퀴즈 웹사이트 wQuiz

오픈소스웨어 팀 프로젝트입니다.

- 주제: 영어 단어 학습 및 퀴즈 웹사이트
- 발표: 12월 2일

## 주요 기능

- 단어 70개 중 10개를 무작위로 출제하는 객관식 퀴즈
- 선택 즉시 정답 여부와 정답 뜻 표시
- 퀴즈 점수와 완료 결과 확인
- 틀린 단어 자동 저장 및 오답 복습 퀴즈
- 오늘 학습 수, 연속 학습일, 누적 정답 수 저장
- 퀴즈 도중 나가면 오늘 학습 수 초기화
- 모바일 화면에 맞춘 반응형 디자인

학습 기록과 오답 목록은 브라우저 `localStorage`에 저장됩니다.

## 실행 방법

`main.html`을 브라우저에서 열거나 VS Code Live Server로 실행하세요. 메인 화면에서 단어 퀴즈와 오답 복습 퀴즈를 시작할 수 있습니다.

## 주요 파일

- `main.html`, `main_js.js`: 메인 화면 및 학습 기록 표시
- `quiz.html`, `quiz_js.js`: 퀴즈 화면과 진행 기능
- `words_data.js`: 영어 단어, 발음기호, 뜻 데이터
- `review.html`, `review_js.js`: 오답 목록과 복습 진입
- `style.css`: 공통 화면 스타일
- `assets/profile-avatar.png`: 프로필 이미지
